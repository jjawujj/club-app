# 모임장부

대학 동아리 행사의 가입 승인, 행사 신청, 입금 확인, 출석(QR), 정산(1/N)을 한 앱으로 관리하는 시연용 프로토타입입니다. 데이터경제학 개인 프로젝트 제출물입니다.

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다. 별도 설치는 필요 없습니다. QR 그림과 글꼴은 인터넷에서 불러옵니다.

- 로그인 화면의 **체험용 계정**(회장, 총무, 운영진, 회원, 가입 대기)을 누르면 바로 로그인됩니다. 비밀번호는 모두 `1234`입니다.
- 역할에 따라 아래 탭(홈, 출석, 관리, 내 QR, 내 정보)이 달라집니다.
- 운영진의 **출석 → QR 스캔**은 휴대폰 카메라로 학생 QR을 읽습니다. 카메라를 쓸 수 없으면 명단에서 고르는 방식으로 바뀝니다.
- 데이터는 그 기기의 브라우저에만 저장됩니다. **내 정보 → 개발자 옵션**에서 기준일을 바꾸거나 처음 상태로 되돌릴 수 있습니다.

## 주요 기능

| 역할 | 기능 |
|---|---|
| 회원 | 학기 가입·재가입 신청, 행사 신청·취소, "입금했어요" 표시, 취소 요청(환불 규칙에 따른 예상 환불액), 개인 출석 QR, 늦은 출석 인증, 정산 결과 확인 |
| 운영진 | 행사 등록(선납형/후불형, 환불 구간), QR 스캔 출석, 초성·학번 검색 출석, 30초마다 바뀌는 늦은 출석 QR, 미출석자 목록, 인원수 대조, 출석 기록, 뒷풀이 명단 불러오기·손님 추가 |
| 총무·회장 | 가입 일괄 승인·카톡방 초대 체크, 입금 확인, 취소·환불 승인, 출석 최종 확정, 정산 확정과 안내문 복사, 미납자 목록, 회비 장부, 권한 관리 |

## 정산 규칙

- **선납형:** 확보금 = 확인된 선납금 − 환불액, 부족분 = 총지출 − 확보금
  - 부족분 > 0: 1인당 = 부족분 ÷ 출석자 수(1원 미만 버림), 버림 차액은 회비에서 부담
  - 부족분 ≤ 0: 추가금 없음, 남은 금액은 회비로 이월
- **후불형:** 1인당 = 총지출 ÷ 출석자 수(손님 포함, 1원 미만 버림)
- 불참자는 환불 없음. 환불 비율은 행사마다 "n일 전까지 m%" 구간으로 설정

## 시연용 단순화

- 실제 서버 대신 브라우저 저장소(localStorage)를 사용합니다. 실제 앱에서는 Firebase나 Supabase 같은 서버 데이터베이스가 필요합니다.
- 늦은 출석 코드 검증은 실제 앱에서 서버가 해야 조작을 막을 수 있습니다.
- 로그인은 브라우저 안에서만 확인합니다. 실제 서비스에서는 서버 인증(Firebase Authentication 등)이 필요합니다.
- 기기끼리 데이터가 공유되지 않습니다. 같은 초기 데이터로 시작하므로 노트북에 띄운 학생 QR을 휴대폰 운영진 화면으로 스캔하는 시연은 가능합니다.
